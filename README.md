# Домашні роботи 1–20

Рішення за наданими скриншотами та файлами уроків. Кожне ДЗ — в окремій папці.
Коментарі та повідомлення програм українською.

## Початок роботи у Windows

Розпакуй архів. Відкрий термінал у папці `homework_all`.
Потрібен Python 3.10 або новіший.

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Можна активувати середовище в CMD командою `.venv\Scripts\activate.bat`.
У командах нижче `python` означає Python цього середовища. Без активації запускай його повним шляхом.
У VS Code вибери `.venv` через Python: Select Interpreter.

## Приклади введення

ДЗ 1: `2 5 10 0 4 7 11 5 8` → `11 6`. Індекс рахується з нуля; при повторенні береться перший.

ДЗ 3: `22 22 24 49 72 98 101 82 51 40 36 24` → `(621.0, 51.75, (101.0, 'July'), (22.0, 'January'))`.
Чотири робочі функції: введення, перевірка, обчислення, виведення; `main` їх викликає.
За однакових мінімумів/максимумів береться перший місяць, як у прикладі.

ДЗ 9:
- №99: введи `20`, Enter, `25`, Enter → `2 5`.
- №177: один запуск — одне число: `1234` → `True`, `1981` → `False`, `12` трактується як `0012` → `False`.
- №291: `125` → `521`; `120` → `21`; `0` → `0`. Для від'ємного числа знак зберігається.
- №818: один запуск — три числа: `10`, `6`, `3` на окремих рядках → `True`. Інший приклад `10`, `6`, `5` → `False`.
- №820: вводь порції на окремих рядках; порожній рядок завершує введення. Після кожної порції друкується залишок, а після кожної повної п'ятірки — її сума.

ДЗ 6: `stash + 3` та `stash - 3` повертають новий об'єкт; зберігай результат через `stash = stash + 3` або `stash += 3`. Початковий об'єкт не змінюється звичайним `+`.
ДЗ 7: positive_only перевіряє саме позиційні аргументи, як в умові.

## Запуск Django (ДЗ 12)

З папки `12_django`:

```bash
python manage.py makemigrations cards
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Відкрий http://127.0.0.1:8000/admin/ і ввійди з власним логіном/паролем. Модель — колекційна картка, є пошук і фільтрація. Налаштування призначені для локального навчання.
Умовою дозволено здати лише модель та адмінку; решта файлів потрібна для самостійного запуску.
